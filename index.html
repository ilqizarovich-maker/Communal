Информация о счетчиках:

Индивидуальные счетчики – учитывают потребление конкретного арендатора.

Групповые счетчики – учитывают потребление группы арендаторов.

Счета от ресурсоснабжающих организаций

Виды счетов:

Общие счета – распределяются между всеми арендаторами с учетом коэффициентов деятельности (электроэнергия, газоснабжение).

Индивидуальные счета – выставляются конкретному арендатору (вывоз ТКО, вода при наличии отдельного договора).

  • Продленный день – 12-16 часов работы (коэфф. 1.3)
  • Круглосуточно – 24/7 работа (коэфф. 1.8)

Методология расчетов

1. Расчет электроэнергии с учетом видов деятельности

Общий принцип: Распределение электроэнергии учитывает потребление по счетчикам, режим работы арендатора и потери в сетях.

Итоговый коэффициент = Коэффициент деятельности × Коэффициент режима работы

2. Расчет газоснабжения (отопление и ГВС)

Общий принцип: Общий счет на здание распределяется между арендаторами с учетом итогового коэффициента.

Шаг 1: Рассчитываем приведенную площадь для каждого арендатора:

Приведенная площадь = Фактическая площадь × Итоговый коэффициент

Шаг 2: Распределяем общую сумму счета пропорционально приведенной площади.

3. Расчет доли НДС

Новое в версии 2.3: Вместо фиксированных МОП используется НДС из счетов РСО.

Принцип распределения:

  1. Извлекается сумма НДС из каждого общего счета РСО
  2. Общая сумма НДС по всем счетам распределяется между арендаторами пропорционально приведенной площади
  3. Если НДС не указан в счете, используется процент по умолчанию из настроек
  4. Индивидуальные счета НДС не распределяются - они полностью относятся к конкретному арендатору

Информация о GitHub Pages

Ваш сайт на GitHub Pages:

https://[ваш-логин].github.io/[репозиторий]/

Как настроить GitHub Pages:

  1. Зайдите в настройки вашего репозитория
  2. Выберите вкладку "Pages"
  3. В разделе "Source" выберите ветку "main" и папку "/ (root)"
  4. Нажмите "Save"

Как создать токен:

  1. Зайдите в Settings → Developer settings → Personal access tokens
  2. Нажмите "Generate new token (classic)"
  3. Выберите права доступа "repo" (полный доступ к репозиториям)
  4. Скопируйте токен и вставьте в поле выше
